# Pudu Grammar

The [Pudu grammar](https://github.com/chrismichaelps/pudu-lang/blob/dev/wiki/grammar/pudu.md) and semantic vault govern this package. Public functions carry explicit types. Functions are values; module functions provide the fluent composition surface. `///` documents each exported declaration in LSP hover, while a `/** @Namespace.Entity.Role — intent */` anchor identifies module and public type boundaries.
