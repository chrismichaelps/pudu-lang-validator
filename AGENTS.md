# Agent operating contract

The versioned vault at `wiki/` governs this package. `fmcf.md` is a private local input and must stay ignored, unstaged, and absent from generated artifacts.

## Re-anchor

Before changing Pudu, read `wiki/00-INDEX.md`, `wiki/architecture/Validation.md`, `wiki/grammar/pudu.md`, the active handoff, and every corresponding source mirror. A source file must have a complete mirrored page and resolved Grill Log before it is created or changed.

## Ownership and review

Name the files owned by each implementation assignment. Contributors share the repository and preserve unrelated work. The implementation author cannot be its sole reviewer. Public API changes require an architecture review; every change requires a wiki parity review.

## Delivery

Follow `CONTRIBUTING.md`. Keep source and mirror pages aligned in one change; update maps, backlinks, and `wiki/CHANGELOG.md`. Work on a feature branch from `dev` once a ready issue exists. Do not add automated authorship attribution to commits, pull requests, or documentation.
